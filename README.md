# Smart Dragon Inventory

نظام إدارة وبحث توافق قطع وإكسسوارات السيارات الخاص بـ Smart Dragon Jordan.

> المشروع حالياً في مرحلة **UI Foundation / Development Preview**.
> Firebase وتسجيل الدخول وإدارة البيانات الحقيقية غير مفعلة بعد.

---

## الهدف من المشروع

المشروع يهدف إلى استبدال البحث النصي المفتوح بنظام أكثر دقة يعتمد على:

**الشركة → الموديل → السنة**

بعد اختيار السيارة، يعرض النظام بيانات التوافق المعتمدة مثل:

- اللمبات
- المساحات
- الشاشات
- وأي أصناف أخرى يضيفها المدير مستقبلاً

الأصناف ليست ثابتة داخل الكود، وسيكون المدير قادراً لاحقاً على إنشاء أصناف جديدة من لوحة الإدارة.

---

## حالة المشروع الحالية

الحالة الحالية:

- واجهة العميل جاهزة كـ Development Preview
- القوائم معطلة عمداً
- لا يوجد اتصال Firebase
- لا يوجد تسجيل دخول
- لا يوجد تعديل أو حذف حقيقي
- لوحة الإدارة عبارة عن Preview فقط
- أساس الذكاء الصناعي موجود لكنه غير متصل بأي API
- أساس التكامل مع مشروع البحث حسب السيارة موجود لكنه غير مفعل
