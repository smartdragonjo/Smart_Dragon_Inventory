# إدارة المستخدمين

## الأدوار

- Owner: الحساب `smartdragonjordan@gmail.com`، يملك صلاحيات الإدارة الكاملة.
- Editor: يضيف ويعدل بيانات التوافق ويرسلها للمراجعة، ولا يعتمد النشر النهائي ولا يحذف ولا يدير المستخدمين.

## إضافة محرر

1. افتح لوحة الإدارة.
2. ادخل إلى **المستخدمون**.
3. اضغط **إضافة محرر**.
4. أدخل بريد Google الخاص بالمحرر.
5. سيظهر المستخدم بحالة **بانتظار أول دخول**.
6. عند أول تسجيل دخول بهذا البريد، ينشئ النظام ملف `users/{uid}` تلقائيًا بصلاحية `editor`.

## التفعيل والتعطيل

- قبل أول دخول: يتم تفعيل/تعطيل الدعوة داخل `user_invites/{email}`.
- بعد أول دخول: يتم تفعيل/تعطيل ملف المستخدم داخل `users/{uid}`.
- حساب المالك لا يمكن تعطيله من اللوحة.

## الأمان

يجب نشر `firestore.rules` الموجودة في جذر المشروع قبل استخدام ميزة الدعوات. قواعد Firestore هي المرجع الفعلي للصلاحيات، وليس إخفاء الأزرار في الواجهة.


## إدارة المستخدم بعد الانضمام
يمكن للمالك تعديل الاسم، تفعيل/تعطيل المستخدم، أو حذف صلاحية دخوله. حذف المستخدم من اللوحة لا يحذف حساب Google/Firebase Authentication نفسه؛ بل يحذف ملف الصلاحية والدعوة حتى يصبح غير مصرح له بالدخول.
